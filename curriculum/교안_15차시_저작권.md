# 15차시 교안: 다른 사람의 작품도 소중해요 - 저작권 이야기

## 기본 정보
- **영역**: 저작권과 디지털 윤리
- **대상**: 초등학교 3~6학년
- **시간**: 40분
- **학습 목표**:
  1. 저작권의 의미와 중요성을 이해할 수 있다.
  2. 올바르게 콘텐츠를 이용하는 방법을 알 수 있다.
  3. 자유롭게 사용할 수 있는 콘텐츠를 찾아 활용할 수 있다.

## 준비물
- 태블릿 PC (학생 1인 1대)
- 활동지 15-1 「저작권 O/X 퀴즈」
- 활동지 15-2 「자유 이용 콘텐츠로 작품 만들기」
- 빔 프로젝터

## 교수·학습 과정

### 도입 (5분)
1. **동기유발 - "내 그림을 누가 가져갔어요!"**
   - 학생이 열심히 그린 그림을 다른 사람이 자기 것이라고 SNS에 올린 상황을 이야기한다.
   - "이런 경험을 하면 기분이 어떨까요?"
   - "이처럼 다른 사람이 만든 것을 함부로 쓰면 안 되는 이유가 있어요."
2. **학습 목표 제시**
   - "저작권이 무엇인지, 콘텐츠를 올바르게 사용하는 방법을 배워봅시다."

### 전개 1 - 저작권 이해하기 (10분)
3. **저작권이란?**
   - "창작물을 만든 사람(저작자)에게 주어지는 권리"
   - "글, 그림, 음악, 사진, 영상, 프로그램 등 모든 창작물에 저작권이 있어요."
   - "별도의 등록 없이도, 만들어진 순간부터 저작권이 생겨요."
4. **저작권이 있는 것들**
   - 친구가 쓴 일기, 작곡가가 만든 노래, 유튜버의 영상
   - 웹툰 작가의 만화, 사진작가의 사진, 프로그래머의 앱
5. **저작권을 지키지 않으면?**
   - 다른 사람의 노력과 시간을 빼앗는 것
   - 법적으로 처벌받을 수 있음 (벌금, 손해배상)
   - 실제 초등학생 수준의 사례: 학교 과제에 인터넷 그림을 무단 사용한 경우

### 전개 2 - 올바른 콘텐츠 이용 방법 (12분)
6. **저작권을 지키는 방법**
   - ① 출처를 밝히기: "이 사진은 ○○에서 가져왔습니다."
   - ② 허락 받기: 사용 전에 저작자에게 동의를 구하기
   - ③ 자유 이용 콘텐츠 사용하기: CCL(크리에이티브 커먼즈) 표시가 있는 것
   - ④ 직접 만들기: 나만의 창작물 만들기
7. **CCL(자유 이용 허락) 표시 배우기**
   - CC BY (출처 표시): 출처만 밝히면 자유롭게 사용
   - CC BY-NC (비영리): 돈을 벌지 않는 용도로만 사용
   - CC BY-ND (변경 금지): 원본 그대로만 사용
   - CC BY-SA (동일 조건): 같은 조건으로 공유할 때 사용
   - 각 표시의 아이콘을 보여주며 쉽게 설명한다.
8. **활동지 15-1 「저작권 O/X 퀴즈」**
   - 15가지 상황을 읽고, 저작권을 지킨 것인지 아닌지 판단한다.
   - 예시:
     - "유튜브 영상의 배경음악을 내 영상에 그냥 사용했다" → X
     - "무료 이미지 사이트에서 CCL 표시를 확인하고 출처를 밝혀 사용했다" → O
     - "친구가 그린 그림을 허락 없이 내 프로필에 올렸다" → X

### 전개 3 - 자유 이용 콘텐츠 활용 실습 (8분)
9. **자유 이용 콘텐츠 사이트 소개**
   - 공유마당 (gongu.copyright.or.kr): 한국저작권위원회 운영
   - 픽사베이 (pixabay.com): 무료 이미지/영상
   - 프리사운드 (freesound.org): 무료 효과음
10. **활동지 15-2 실습: 자유 이용 콘텐츠로 카드 만들기**
    - 태블릿으로 자유 이용 이미지 사이트에 접속한다.
    - 마음에 드는 이미지를 찾아 저장한다.
    - 그 이미지를 활용하여 간단한 인사 카드를 만든다.
    - 반드시 출처를 표기하는 연습을 한다.
11. **작품 공유**
    - 완성된 카드를 2~3명이 발표하고, 출처 표기가 잘 되어 있는지 확인한다.

### 정리 (5분)
12. **핵심 내용 정리**
    - ① 모든 창작물에는 만든 사람의 저작권이 있다.
    - ② 다른 사람의 창작물을 사용할 때는 허락을 받거나 출처를 밝힌다.
    - ③ 자유 이용 콘텐츠(CCL)를 활용하면 합법적으로 사용할 수 있다.
13. **다음 차시 예고**
    - "다음 시간에는 '내가 보고 싶은 것만 보고 있지 않은지' 확증편향에 대해 알아볼 거예요!"

## 평가 기준
| 평가 요소 | 상 | 중 | 하 |
|-----------|---|---|---|
| 저작권 개념 이해 | 정확히 설명하고 예시 제시 가능 | 기본 개념을 이해함 | 이해가 부족함 |
| 올바른 이용 방법 | CCL 표시를 구분하고 활용 가능 | 출처 밝히기의 필요성을 이해함 | 이해가 부족함 |
| 자유 이용 콘텐츠 실습 | 사이트에서 검색하고 출처 표기까지 완료 | 안내를 받아 완료함 | 실습이 어려움 |

## 지도상 유의점
- 저작권 위반 사례를 다룰 때 처벌을 강조하기보다 "존중"의 가치를 강조한다.
- 학생들이 이미 저작권을 위반한 경험(사진 무단 사용 등)이 있을 수 있으므로, 비난하지 않는다.
- 자유 이용 콘텐츠 사이트 접속 시 부적절한 콘텐츠에 노출되지 않도록 검색어를 안내한다.
- 학생 자신도 저작자가 될 수 있음을 강조하여 동기를 부여한다.
